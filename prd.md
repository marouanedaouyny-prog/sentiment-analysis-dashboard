# PRD: Sentiment Analysis Dashboard

## 1. Project Overview
A platform that scrapes reviews from major sites (Google, Yelp, Amazon) and uses the Gemini API to analyze and visualize the overall sentiment of customer feedback.

## 2. Target Audience
- Brand Managers
- Marketing Teams
- Product Designers

## 3. Key Features
- **Review Scraping Engine:** Fetch reviews from multiple platforms automatically.
- **Sentiment Scoring:** Categorize reviews as positive, neutral, or negative.
- **Topic Extraction:** Use AI to identify key themes (e.g., "customer service," "pricing").
- **Alert System:** Notify users of spikes in negative sentiment.

## 4. Tech Stack (CV Reference)
- **Scraping Engine:** Python with Selenium/Playwright (Fetching reviews from dynamic sites).
- **AI Core:** Gemini API for advanced sentiment and topic analysis.
- **Frontend:** Next.js and Tailwind CSS (Data visualization and reporting).
- **Database:** MongoDB for flexible review and analysis storage.

## 5. Roadmap
- **MVP:** Single source scraping and basic sentiment scoring.
- **V1:** Multi-source aggregation and detailed topic extraction.
- **V2:** Sentiment trend forecasting and direct customer response tools.
